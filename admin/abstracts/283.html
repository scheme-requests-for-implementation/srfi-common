This SRFI focuses on the introspection and type inference sides of typing / checking. It provides several useful procedures deriving types / checks for arbitrary data. procedure-check-of and check-of work with checks, as in SRFI 253. procedure-type-of and type-of work with implementation-specific types. type->check allows one to turn implementation-specific types into portable checks, while check->sexp provides a way to serialize opaque checks into more readable s-expressions.
